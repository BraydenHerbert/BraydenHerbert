Battery-Powered AI Smart Camera

Lead designer for the architecture and 10-layer controlled-impedance PCB of a battery-powered AI smart camera. The board carries high-speed MIPI CSI-2, a dual-MCU and dual-camera architecture, two-way audio, and a low-power sensor stack. Designed a dual-battery power path drawing roughly 0.75 mA on GPIO-interrupt wake with WLAN active.

Quantum Dot Transimpedance Amplifier PCB

Designed a dual transimpedance amplifier PCB to read µA-scale photocurrent from quantum dot fluorescence. Built around the OPA2377 with an 8.3 kΩ feedback resistor and 144 pF compensation, set for a 133 kHz bandwidth. Characterized gain, bandwidth, and noise in LTspice, reaching 0.79 nA RMS input-referred noise across the band, thermal-limited at low frequency and op-amp-and-capacitance-limited near the band edge.

Signal Analyzer and Generator PCB

Designed a USB-powered, single-channel mixed-signal PCB in KiCad for low-frequency signal analysis and generation using an STM32. Routed high-speed USB with 90 Ω impedance control, differential pair routing, and length matching. Used switch-mode regulators for digital power and linear LDOs for low-noise analog supply, with an ADC/DAC and analog front-end for generating and receiving signals. Bias generator simulated in LTspice.

Hardware-in-the-Loop Power Supply PCB

Designed a 4-layer PCB for powering hardware-in-the-loop testing, managing power distribution across six vehicle systems. Integrated voltage regulators, logic switches, and current sensors controlled by an ESP32 using Altium and LTspice.

6502-based 8-Bit Computer

Built a functional 8-bit computer with the 6502 processor, including assembly programming and hardware design based on Ben Eater's design. Integrated circuits for memory management, clock generation, and address decoding.

Smart Medication Monitoring PCB

Designed a non-contact liquid-level monitoring device using a 4-channel I2C capacitance-to-digital conversion system, based on an ESP32 MCU with USB-C charging and an integrated web server for remote monitoring.

Model Wing with Electrical Control System

PWM-based control circuitry and firmware to adjust a linear actuator on a 1:5 scale F1 wing.
